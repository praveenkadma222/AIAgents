## Run the chatbot (Windows PowerShell)

If PowerShell reports that `pipenv` is not recognized, install it with Python:

```powershell
py -m pip install --user pipenv
```

From the repository root, install the dependencies from the project's Pipfile
and run the Streamlit app:

```powershell
Set-Location .\AI-Chatbot-RAG
py -m pipenv install
py -m pipenv run streamlit run phase1.py
```
